- Edit dimensions, refresh, return home, reopen exact geometry, back and forward navigation.
- Real recent-project search, rename persistence, cancel deletion with Escape and confirm deletion.

- Existing geometry/net/folding, texture, SVG, paginated PDF, assembly guide and calibration behavior remains covered by the existing suite.

## Data and route compatibility

`paper-studio.projects.v1` stores stable IDs, modification timestamps and validated project documents. The existing `paper-studio.editor-workspace.v1` and isolated sample draft remain readable, and existing JSON versions migrate through `parseProject`. No cloud, account or network-backed storage is introduced.

`/` is the home dashboard; `/studio`, `/studio/` and `/studio?sample=tetrahedron` remain supported. The prior cinematic experience is retained at `/showcase` and `/showcase/`.

The hero is an interactive study of the supported cuboid and its actual net. It does not advertise a composite architectural shape as an available template. Project thumbnails show canonical geometry, rather than inventing image previews or recent projects.

## Release procedure

1. Require successful checks on each PR's current HEAD.
2. Merge #138, then #139, then the #137 release PR through `scripts/merge-pr-checked.mjs` using normal merge commits.
3. Confirm linked issues close and merged remote branches are removed.
4. Update local main without including the user's existing `.gitignore` change.
5. Inspect the linked Vercel production project and deploy the verified main tree through the approved host flow when automatic deployment has not published it.
6. In a fresh Chromium context on the production alias, verify the home entry, project creation, templates, editor refresh/restoration and zero unexpected console/page errors. Capture production screenshots separately from these local screenshots.

Local verification is not evidence of CI, production deployment, physical printing accuracy or another browser's behavior. Remote CI and production outcomes are reported separately after observing them.
